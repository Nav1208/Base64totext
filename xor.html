XOR to Text Converter

Paste encoded byte values and a repeating XOR key, then decode the result into text.


    

    
How it works
Each encoded value is XORed with the matching key value. When the key is shorter than the data, it repeats from the beginning: decoded[i] = encoded[i] XOR key[i % key.length].
Decimal values are used by default. Hexadecimal values are supported with an 0x prefix, such as 0x46, 0x22.
