07 / XOR Lab
Single-Byte XOR Decoder










Result will appear here.


For “Hex” mode, enter byte pairs such as 1b070f0f0a or 1b 07 0f 0f 0a. Brute force ranks keys using a simple printable/English heuristic; it does not guarantee the correct key.











Tip

If a challenge says “single-byte XOR,” try the brute-force button first. Then inspect the readable candidates and test the most plausible key.
